# PWA

Installable, offline-capable gunshop. Built with `vite-plugin-pwa` — the
manifest and service worker are generated at build time, not hand-written.

## 1. Application shell

- `index.html` — minimal static shell, mounts `src/main.jsx`.
- `src/App.jsx` — the shell: header, nav, main content area. Routes render inside the shell, never a full-page reload.

## 2. Web app manifest

- Configured via the `manifest` option in `vite.config.js`; the plugin emits
  `manifest.webmanifest` and injects the `<link rel="manifest">` tag.
- Icons live in `public/` png/svg (at least 192px and 512px for installability).

## 3. Service worker

- Generated by the plugin's Workbox `generateSW` strategy, configured via the
  `workbox` option in `vite.config.js`.
- Registration is injected into `index.html` (`registerType: 'autoUpdate'`), so
  `src/main.jsx` does not register it manually.
- `devOptions.enabled` is on, so `npm run dev` serves and registers the SW too.
  Installability still requires a secure context: `localhost` or HTTPS. Over a
  LAN IP (`vite --host`), the browser refuses to register the SW.
- Precache globs cover the built app shell plus `public/` assets.
